Inheritance Types & super() Execution (5 Core Scenarios)

Comprehensive study of object-oriented Inheritance architecture in Java, detailing Single, Method Reusability, Multilevel, Hierarchical, and Constructor Chaining with super().

IMPORTANT Employee
1. Basic / Single

Employee Subclassing

Base Employee attributes (name, salary) inherited by specialized Developer and Tester subclasses.

IMPORTANT Vehicle
2. Method Reusability

Vehicle Operations

Subclasses Car and Bike directly reuse parent methods start() and stop() without rewriting logic.

IMPORTANT BankAccount
3. Multilevel Inheritance

3-Tier Banking Hierarchy

Chain of inheritance: BankAccount → SavingsAccount → PremiumSavingsAccount inheriting accumulated traits.

IMPORTANT Product
4. Hierarchical Inheritance

E-Commerce Catalog

Single parent Product branches out to three sibling child classes: Electronics, Clothing, and Books.

IMPORTANT Person
5. super() Constructor Chaining

University Student

Subclass Student invokes parent constructor super(name, age) as its first executable instruction.

Interactive console while-loop with Scanner to execute each scenario or run all 5 sequentially.
