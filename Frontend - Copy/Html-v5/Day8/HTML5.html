1. What is <!DOCTYPE html> ?

<!DOCTYPE html>is the first line of every HTML5 document. It tells the web browser that the page is written using HTML5, which is the latest version of HTML. This declaration is not an HTML tag; it is an instruction for the browser. When the browser sees , it displays the page in Standards Mode, ensuring that HTML and CSS behave consistently across modern browsers. Without this declaration, browsers may switch to Quirks Mode, where they try to imitate older browser behavior. This can cause layout issues, CSS inconsistencies, and unexpected rendering problems. Therefore, it is considered a best practice to always include as the very first line of every HTML document.

Implementation :

<!DOCTYPE html>


2.What is <html lang="en">

<html lang="en" <html>The lang="en" attribute specifies that the language of the webpage is English. This helps search engines, screen readers, translation tools, and accessibility software correctly identify the language of the page. If your webpage is written in another language, you can change this value (for example, lang="ta" for Tamil or lang="fr" for French).

Implementation :

<html lang="en">




3.What is <meta charset="UTF-8">

What is the charset meta tag ?


The charset meta tag tells the browser which character encoding is used in the HTML document. Today, the recommended encoding is UTF-8, which supports almost every language and symbol in the world, including English, Tamil, Hindi, Chinese, Arabic, emojis, and many special characters. Without specifying UTF-8, some characters may appear as strange symbols or question marks because the browser may interpret the text using the wrong encoding. Placing this meta tag near the beginning of the section ensures the browser reads the document correctly from the start. Using UTF-8 also improves compatibility across different operating systems and browsers.

Implementation :

<meta charset="UTF-8">




4.Viewport meta tag <meta name="viewport">

What is the viewport meta tag?


The viewport meta tag controls how a webpage is displayed on different screen sizes, especially on smartphones and tablets. The viewport is the visible area of the webpage on the user's device. Without this tag, mobile browsers often display the page as if it were designed for a desktop screen, making the content appear very small and difficult to read. The value width=device-width tells the browser to make the webpage width match the width of the device's screen. The value initial-scale=1.0 sets the initial zoom level to 100%, so the page is displayed at its normal size when it first loads. This meta tag is an essential part of responsive web design, allowing websites to adapt properly to desktops, laptops, tablets, and mobile phones.

Implementation :

<head
meta charset="UTF-8" meta name="viewport" content="width=device-width, initial-scale=1.0"
head>
